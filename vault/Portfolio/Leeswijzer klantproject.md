# Leeswijzer — collectie klantproject

> [!info] Waar dit hoort
> Dit is de tekst voor het veld **Collection description** in Portflow.

## Wat hier staat

Het klantproject heb ik gedaan voor Studio040, de omroep in Eindhoven. We
hebben een redactietool gebouwd die van één artikel meerdere vormen maakt: een
korte samenvatting, een langere tekst, een Engelse versie en een audioversie.
Het uitgangspunt was dat een redacteur met één klik vier dingen krijgt waar hij
anders vier keer mee bezig is — en dat hij kan zien wat het model heeft gedaan.

## In welke volgorde

1. **`AI Editor — Studio040`** (applicatie en repository) — begin bij het
   werkende product. In de repository staat een README met de opzet, hoe je
   hem start en welke keuzes we hebben gemaakt.
2. **`Posterpresentatie`** — de presentatie waarmee we het project hebben
   toegelicht.
3. **`Reflectie Studio040`** — mijn eigen aandeel en wat ik ervan heb geleerd
   (volgt).
